# validity-rs.github.io

The website of [validity-rs](https://github.com/validity-rs/validity-rs): https://validity-rs.github.io/

**[Website](https://validity-rs.github.io/)** · [Driver and service](https://github.com/validity-rs/validity-rs) · [Fingerprints app](https://github.com/validity-rs/fingerprint-settings) · [APT repository](https://validity-rs.github.io/apt/) · [Tool reference](https://validity-rs.github.io/docs.html)

Plain HTML and CSS, no build step: `index.html` (the one-pager), `docs.html` (the tool reference), `style.css`. GitHub Pages serves `main` as is. The APT repository at `/apt` is the [validity-rs/apt](https://github.com/validity-rs/apt) repository's own Pages site.
